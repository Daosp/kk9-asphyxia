# KK9 Asphyxia Plugin

Asphyxia's plugin for Mahjong Fight Club Extreme. We tested the following versions:
- KK9:J:A:A:2025082501 (A cabinet)
- KK9:J:B:A:2025082501 (B cabinet)
- KK9:J:F:A:2025082500 (HG cabinet)
- KK9:J:A:A:2025072900 (Central Unit)

This plugin has support for saving user data, including customization, and online play through virtual local net (Radmin, ZeroTier etc.).

## Netplay

To play online, you need to do the following steps:
1. NetFixes MUST be enabled (not add -netfixdisable on spice2x)
2. Copy and paste your IP and netmask in Radmin and another program into your spicecfg (Preferred Network Adapter's IP and Preferred Network Adapter's Subnet)
If you don't know where to find this subnet mask, you can check in ipconfig.
3. Your friends should do the same too.
